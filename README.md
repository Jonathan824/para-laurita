# para-laurita

Pequeño sitio estático (GitHub Pages) con sorpresas para Laura.

```
index.html        Portada: menú con una "puerta" por experiencia
nav.css           Barra de navegación compartida (Inicio · otra página)
rosa/index.html   La rosa eterna y la carta
runas/            El sello de las runas (index.html, style.css, app.js, data.js)
```

Para añadir una experiencia nueva: crea una carpeta con su `index.html`,
inclúyele `<link rel="stylesheet" href="../nav.css">` y la barra `<nav class="nav-sitio">`,
y agrega una `<a class="puerta">` más en la portada.
